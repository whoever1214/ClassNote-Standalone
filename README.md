# ClassNote — 课堂笔记助手（单机版）

> 一款**纯客户端**课堂笔记工具：课堂录音 + 自动截屏 + 本地语音转文字（STT）+ 本地图片识别（OCR）+ LLM 生成结构化笔记。
> 无需任何服务端，开箱即用。

**系统要求**

- Windows 10 1809（build 17763）或更高 / Windows 11，**x64**
- 内存 ≥ 8 GB（STT 模型加载峰值约 600 MB）
- [Microsoft Edge WebView2 运行时](https://developer.microsoft.com/microsoft-edge/webview2/)（Win11 及较新 Win10 通常已内置；缺失时安装程序会提示）

**安装说明**

- 按**当前用户**安装到 `%LOCALAPPDATA%\Programs\ClassNote`，**无需管理员权限**
- 安装向导支持简体中文 / 繁体中文 / English

首次启动后点击主页面右上角**「设置」**（齿轮图标）配置 LLM API Key 即可使用完整的笔记生成功能。

## 核心特性

- **课堂录音**：NAudio 采集 16kHz 单声道 WAV，自动保存到本地。**声音来源可选（v0.6.0 固定三种：仅麦克风 / 仅系统声音 / 麦克风和系统声音）**：麦克风（教室现场）/ 系统声音（设备外放，WASAPI 回环，可指定播放设备）/ 两者**分开各录一份、分别转写**——两路转写结果分别标注来源后交给 LLM，笔记里能看出哪些内容来自「现场」、哪些来自「课件」（代价是语音识别跑两次，处理时间约翻倍）；手动录音与定时录音共用「设置 → 录音设置」里的默认来源与设备。
- **自动截屏**：周期性全屏抓取 + pHash 变化检测，智能区分"批注 / 新幻灯片 / 视频"三类画面。
- **本地 STT**：SenseVoice-Small ONNX（INT8 量化）+ onnxruntime CPU 推理，中文识别准、自带标点，全程离线。**模型全进程只加载一次**（v0.7；旧版每个录音会话重载一次 241MB 模型，冷盘可达 33 秒），**并且闲置 10 分钟后自动释放、下次录音开始前重新预热**——实测加载后工作集 551MB → 闲置释放后 64MB（−488MB），重载对用户不可见；托盘常驻的软件因此不再整天占着 600MB。
- **更快产出笔记（v0.7，边录边转写）**：录音期间就按 30 秒一块把语音转成文字，**下课时绝大多数内容已经转完**，只补最后不足一块的部分；截图一落库就顺手做 OCR，转写与 OCR 并行跑。课堂期间**最多只占一半逻辑核**，并且检测到**全屏放映 / 视频播放 / 电池供电**时自动降速让路（设置 →「录音设置 → 课堂占用」可选 关闭 / 自动 / 极速；关闭时行为与 v0.6.0 完全一致）。转写文本与"录完整段再转"**逐字相同**（有回归测试与真机对拍工具 `devtools/NoteBench` 把关：95 秒素材逐块一致）。附带好处：中途崩溃/断电不再白跑（按块落库，重启只补缺的块），点「结束录音」不再卡在复制音频文件上。
- **本地 OCR（可选内网服务）**：默认调用 Windows 10/11 内置 OCR 引擎（Windows.Media.Ocr），**录音期间即完成识别**（v0.7），重复截到的同一张幻灯片其 OCR 文本会被去重，减少交给 LLM 的冗余内容。设置 →「OCR 识别」可切换为**内网自建的 PaddleOCR 服务**（hubserving `/predict/ocr_system` 或 PaddleX `/ocr` 两种协议，支持访问密钥与超时，服务失败自动回退内置引擎并进入冷却，不会让整节课的课件文字消失）。素材送进提示词前还会做一轮**确定性字符级降噪**（汉字逐字空格合并、公式行全角转半角、`m 主 n`→`min`；**绝不合并 `1 7 3 5 9 4 8` 这类数字序列**，实测 OCR 体积减少 35.6%）。部署与设置见 [OCR 服务设置与部署](docs/OCR-服务设置与部署.md)。
- **数学公式正确渲染（v0.7 修复）**：笔记页用内置离线 MathJax 排版公式。**修复前每一对括号都会被当成公式**——`d[i][j]` 显示成「d / i / j」三行居中大字，`f(n-1)+1` 甚至变成 `f𝑛 − 1 + 1`（括号消失、变量变斜体，数学语义被改）；同一份笔记实测：修复前 **59 个假公式**、修复后 **0 个**。这是**渲染侧**缺陷，**已有笔记升级后直接正常显示，无需重新生成**。同时提示词新增"公式用 `$...$` 包裹、只补分隔符不改内容"的要求，让公式真正排成数学样式。
- **LLM 笔记生成**：调用 OpenAI 兼容 API（默认 DeepSeek），把"转写 + 截图文字"整理为 Markdown 笔记。**只保留「课程标题 / 核心知识点 / 重点及易错点」三部分，核心知识点（解题模板、解题技巧、公式定理、定义）要求照抄原文、不改写不概括，并删除例题与解析、师生问答（v0.6.0）**；**长课程自动分段生成（v0.6.0）**——素材超限时分段整理成**结构化条目**，再由程序**按标题确定性去重** → 一次全局逻辑排序与连贯性润色 → **逐条回校**（正文对不上就整体退回原条目拼装并留痕），使长文本合并不会悄悄删条或改写内容。**设置分「API 配置 / 录音设置」两个页签（v0.5.0）**：填好供应商地址与 API Key 后**自动拉取可用模型并以下拉选择**（也支持手输自定义模型名）。
- **PDF 导出**：笔记本地渲染为 PDF（QuestPDF），支持单条导出到桌面，或**勾选多条批量导出**到指定文件夹（自动跳过尚未生成笔记的记录，重名文件自动追加序号）。**行内标记不再泄漏进 PDF（v0.7）**：`**加粗**` 渲染为真加粗、`$公式$` 与反引号被正确消化、编号列表（`1.` / `2)` / `1、`）终于能被识别；公式以原文呈现（QuestPDF 不做数学排版）。
- **记录管理**：最近记录支持**勾选 / 全选**（三态）、**批量导出 PDF**、**批量删除**（连同录音 / 截图 / 笔记一并移除），自动轮询刷新期间勾选状态不丢失。
- **科目筛选与右键操作（v0.4.3）**：主页「最近记录」顶部可按**科目筛选**（默认「全部课程」，按最近时间排序；全选 / 批量导出 / 删除只作用于筛选出的记录，不会误删被筛掉的）；每条记录的时间戳带**星期几**，**右键单条记录**可直接「查看笔记 / 导出 PDF / 删除」。**v0.7 修复**：筛选下拉此前有一个会让**列表整片空白**的缺陷——刷新候选集时清空 `ItemsSource`，WPF 会把 `SelectedItem` 推成 null 并写回筛选条件，于是变成"筛一个不存在的科目"，记录全被藏起来（页面只剩「当前科目下暂无记录」）。现在候选集改为原地增删、筛选条件遇到空值一律回退「全部课程」，并有用真 ComboBox 复现该机理的回归测试把关。
- **数据本地化**：会话 / 截图 / 笔记 / 每周课表全部存于本机 SQLite（`%LOCALAPPDATA%/ClassNote/classnote.db`）。
- **定时记录 · 每周课表（v0.4.0）**：可视化编辑课表（「每周课表」七天时间轴网格，每天一列；课块高度按课程**真实时长等比**、相邻课次之间强制留间隙，**相邻的 10 分钟短课 / 45 分钟连堂课都不会互相覆盖**），到点**自动开始录音、下课自动结束**；**后台静默启动**（到点自动录音不弹出主界面，仅发托盘气泡提醒）；**托盘常驻 + 开机自启**（登录即驻留托盘，关闭主窗口不退出录音），定时使用的**声音来源与设备**（v0.5.0 起支持麦克风 / 系统声音 / 混合）可在设置中指定；唤醒后错过 ≤10 分钟自动补录、已在录音时自动跳过本节。
- **现代界面**：「云白 + 靛蓝」轻量主题，圆角卡片布局、渐变按钮、状态胶囊列表、录音呼吸指示、页面切换动效（样式体系集中于 `ClassNote/App.xaml`）。
- **流畅交互**：全局**平滑滚轮**（缓动动画 + 按视口比例自适应的步长，替代默认逐行跳变；Shift+滚轮横向滚动），覆盖主页列表与设置窗口。

## 从源码构建

### 环境要求

- [.NET SDK 8.0](https://dotnet.microsoft.com/download/dotnet/8.0) 或更高
- Windows 10/11 x64（WPF 项目，仅支持 Windows）
- Visual Studio 2022（可选，便于调试 XAML）

### 1. 还原 SenseVoice 模型（**必要**）

模型二进制约 **230 MB**，属非源码资产，**未纳入版本库**（见 `.gitignore`）。请将下列文件放入 `ClassNote/Models/sensevoice/`：

```
ClassNote/Models/sensevoice/model_quant.onnx   # INT8 量化模型
ClassNote/Models/sensevoice/tokens.json
ClassNote/Models/sensevoice/am.mvn
```

模型可从 [SenseVoice](https://github.com/FunAudioLLM/SenseVoice) 官方仓库获取并自行导出为 ONNX。

### 2. 编译

```bash
dotnet restore                 # 使用项目内的 NuGet.config（nuget.azure.cn 镜像源）
dotnet build -c Release
```

生成产物位于 `ClassNote/bin/Release/net8.0-windows10.0.19041.0/`。

### 3. 运行

确保输出目录下存在 `models/sensevoice/` 后，双击 `ClassNote.exe` 启动。

### 4. 打包安装程序（可选）

需先安装 [Inno Setup 6](https://jrsoftware.org/isinfo.php)，然后运行一键脚本：

```bash
build-installer.bat
```

脚本会依次执行：自包含发布（`win-x64`）→ 校验关键载荷文件 → 用 Inno Setup 编译。
产物：`dist/ClassNote-1.0.1-setup-x64.exe`。

> **发布前版本号维护（易漏点）**：版本号是**手写常量**，需同步 3 处 ——
> `ClassNote/ClassNote.csproj`（`Version`/`FileVersion`/`AssemblyVersion`）、
> `installer/ClassNote.iss`（`MyAppVersion`）、
> `build-installer.bat` 末尾的输出文件名提示。

### 5. 测试

```bash
dotnet test ClassNote.Tests/ClassNote.Tests.csproj
```

真机录音冒烟验证（可选，需有声卡；每种声音来源各录 N 秒并校验产物格式与时长）：

```bash
dotnet run --project devtools/AudioProbe -c Release -- <输出目录> 2
```

笔记链路实测（可选，需 `ClassNote/Models/sensevoice/` 下的模型；验证"边录边转写 = 整文件转写"并测各阶段耗时）：

```bash
dotnet run --project devtools/NoteBench -c Release -- chunks   <wav>            # 分块计划（不需要模型）
dotnet run --project devtools/NoteBench -c Release -- identity <wav>            # 逐块 + 整体逐字对拍
dotnet run --project devtools/NoteBench -c Release -- classroom <wav>           # 课堂模拟：测课堂占用与课后残余等待
```

退出码 0 表示逐字相同，可直接接进 CI。实测数据见 [`TestResults/bench/v0.7-提速实测报告.md`](TestResults/bench/v0.7-提速实测报告.md)。

笔记渲染校验（可选，需 WebView2 运行时；验证公式渲染并输出截图，`--legacy-config` 会故意复现历史事故）：

```bash
dotnet run --project devtools/NoteRender -c Release -- --demo
dotnet run --project devtools/NoteRender -c Release -- --session <会话id前缀> --out note.png   # 渲染真实笔记
```

主回路实机审计（21.9 分钟双路录音的真实数据）：[`TestResults/bench/v0.7-主回路审计报告.md`](TestResults/bench/v0.7-主回路审计报告.md)。

## 项目结构

```
ClassNote-Standalone/
├─ ClassNote/                  # 主程序（WPF）
│  ├─ Models/                  # 数据模型（会话/截图/笔记/课表条目）
│  ├─ Services/                # 录音、截屏、STT、OCR、LLM、仓库、课表引擎
│  ├─ ViewModels/              # MVVM 视图模型
│  ├─ Views/                   # 页面与窗口（主页/录音/课表/设置/编辑器）

│  └─ Models/sensevoice/       # STT 模型（不入库，需自行放置）
├─ ClassNote.Tests/            # xUnit 单元测试
├─ devtools/                   # 开发辅助工具（渲染校验 / 自启动探针 / 音频冒烟 / NoteBench 笔记链路实测 / NoteRender 笔记渲染校验）
├─ docs/                       # 开发文档、部署文档、UI 渲染图
├─ installer/                  # Inno Setup 安装脚本与中文语言包
├─ build-installer.bat         # 一键打包脚本
└─ ClassNote.sln
```
