# ClassNote 单机版 — 部署文档

> 面向部署 / 分发 / 运维人员：从源码构建发布包、分发给最终用户、安装配置与故障排查。
> 适用版本：无服务端单机版（SenseVoice ONNX STT）。

---

## 1. 系统要求（最终用户）

| 项目 | 最低 | 推荐 |
|------|------|------|
| 操作系统 | Windows 10 1809 (x64) | Windows 10 22H2 / Windows 11 x64 |
| 处理器 | x64，4 核 | 8 代 i5 以上 |
| 内存 | 8 GB | 16 GB || 磁盘 | 2 GB 可用 | 4 GB（含录音/截图增长） |
| .NET 运行时 | .NET 8 Desktop Runtime（若为自包含发布则免） | — |
| WebView2 Runtime | Windows 10/11 通常已内置；缺失时提示安装 Evergreen 版 | — |
| 麦克风 | 可用录音设备 | 独立麦克风/耳机 |
| 网络 | 仅 LLM 笔记生成需要（DeepSeek API） | 稳定网络 |

> **重要**：STT 模型加载峰值内存约 600MB（240MB 模型 + 推理中间张量），
> 8GB 内存即可顺畅运行；若机器内存较小，长音频可分块推理（代码已按 30s 分块）。
> **v0.7 起模型闲置 10 分钟会自动释放**（实测加载后 551MB → 闲置后 64MB），
> 下次录音开始时会重新预热，因此不会在"点结束录音"时才等加载——托盘常驻不再整天占着 600MB。

## 2. 发布 / 打包步骤

### 2.1 从源码生成发布包

在**开发机**（已装 .NET 8 SDK）的项目根目录执行。**推荐直接用自包含发布**（目标机无需装 .NET）：

```bash
# 1) 自包含 x64 绿色包 → publish/（v0.7 实测 461.4MB / 520 个文件，可直接拷给用户运行）
dotnet publish ClassNote/ClassNote.csproj -c Release -r win-x64 --self-contained true -o publish/

# 2) 自包含发布 + 校验关键载荷 + 编译安装程序（一键脚本，产物在 dist/）
build-installer.bat
```

> ⚠️ **两个输出目录别搞混**：
> - `publish/` = 绿色免安装包（上面第 1 条命令的产物，拷给用户双击 `ClassNote.exe`）；
> - `dist/app` = **安装程序**的打包源：`build-installer.bat` 会先清空它再自包含发布，
>   然后由 `installer/ClassNote.iss` 的 `Source: "..\dist\app\*"` 打进安装包。
>   只更新 `publish/` **不会**改变安装包内容——要让安装包带上新代码，必须跑 `build-installer.bat`。

`build-installer.bat` 依次做三件事：`dist/app` 自包含发布 → 校验关键载荷文件（模型三文件、
`onnxruntime.dll`、`SQLite.Interop.dll`、`WebView2Loader.dll`、`mathjax-tex-svg.js`）→ 用 Inno Setup 6 编译，
产物为 `dist/ClassNote-<版本>-setup-x64.exe`。安装程序需要本机已装
[Inno Setup 6](https://jrsoftware.org/isinfo.php)。

若目标机已装 .NET 8 Desktop Runtime、想减小分发体积，也可改用**依赖框架版**：

```bash
# 依赖框架版（体积小，但目标机必须装 .NET 8 Desktop Runtime）
dotnet publish ClassNote/ClassNote.csproj -c Release --self-contained false --no-restore -o publish/
```

> - 发布命令对 **csproj** 发布（对 `.sln` 发布不支持 `-o/--output`）；`--no-restore` 仅用于已还原过的本地发布。
> - 首次做自包含发布需联网还原 `Microsoft.NETCore.App.Runtime.win-x64` 运行时包。
> - `ClassNote.csproj` 已将 `models/sensevoice/`（模型三文件）与 `assets/mathjax-tex-svg.js`
>   配置为 `CopyToOutputDirectory=PreserveNewest`，发布时自动带入；`LatoFont/`（QuestPDF 字体）随包发布。
> - **发布前先同步版本号**（手写常量，共 3 处）：`ClassNote/ClassNote.csproj`、`installer/ClassNote.iss`、
>   `build-installer.bat` 末尾的输出文件名提示。
> - 建议**先删掉整个 `publish/`（或 `dist/app`）再发布**：publish 是增量覆盖，旧版本的残留文件
>   （例如已改名的程序集）会留在目录里混入分发包。
> - **v0.7 已执行**：清空 `publish/` 后重新自包含发布 → 520 个文件 / 461.4MB，
>   `ClassNote.dll` 456,192 字节，关键载荷全部就绪（校验命令见 §2.2 末尾）。

### 2.2 分发内容检查清单

发布目录 `publish/` 必须包含：

| 文件 / 目录 | 必含 | 说明 |
|------------|------|------|
| `ClassNote.exe` | ✅ | 主程序 |
| `ClassNote.dll` / `ClassNote.deps.json` / `ClassNote.runtimeconfig.json` | ✅ | 程序集与运行时描述 |
| `*.dll` | ✅ | 依赖程序集（NAudio、OnnxRuntime、QuestPDF、SQLite、Markdig、WebView2 等） |
| `onnxruntime.dll` | ✅ | onnxruntime 原生库（自包含 win-x64 发布时**位于根目录**，不在 `runtimes/` 下） |
| `SQLite.Interop.dll` | ✅ | SQLite 原生库（同上，**位于根目录**） |
| `WebView2Loader.dll`（根目录 + `runtimes/win-x64/native/`） | ✅ | WebView2 加载器（两处都会出现，属正常） |
| `hostfxr.dll` / `hostpolicy.dll` / `coreclr.dll` | ✅ | **自包含发布**的 .NET 运行时（依赖框架版没有这三个，改由系统 .NET 提供） |
| `models/sensevoice/model_quant.onnx` | ✅ | **SenseVoice 模型（约 240MB），缺失则 STT 不可用** |
| `models/sensevoice/tokens.json` | ✅ | CTC 词表 |
| `models/sensevoice/am.mvn` | ✅ | CMVN 参数 |
| `assets/mathjax-tex-svg.js` | ✅ | 笔记页面公式渲染（MathJax） |
| `LatoFont/` | ✅ | QuestPDF 字体（PDF 导出） |

发布后可用一行命令核对（与 `build-installer.bat` 的校验清单一致；缺任一文件都会打印缺失项）：

```powershell
$out = "publish"
$need = @("models\sensevoice\model_quant.onnx","models\sensevoice\tokens.json","models\sensevoice\am.mvn",
          "onnxruntime.dll","SQLite.Interop.dll","runtimes\win-x64\native\WebView2Loader.dll",
          "assets\mathjax-tex-svg.js","ClassNote.exe","ClassNote.dll")
$missing = $need | Where-Object { -not (Test-Path (Join-Path $out $_)) }
if ($missing) { "缺失: $($missing -join ', ')" } else { "关键载荷就绪" }
```

> **v0.7 附带说明**：本次改动没有新增任何随包文件（新增的都是代码），因此检查清单不变；
> 唯一新增的工程是**开发工具** `devtools/NoteBench`，它**不会**进入 `publish/` 或安装包
> （不是主程序引用项，只用于发布前的链路验收）。

### 2.3 分发方式

发布完成后，**`publish/` 目录即为最终成品**（v0.5.0 起为**自包含**形态，目标机免装 .NET），
直接将该目录（含全部文件/子目录）拷贝或通过 U 盘 / 内网 / 网盘分发给目标机即可，**无需压缩打包**：

```bash
# publish/ 目录本身就是可直接运行的分发包
# 目标机：把整个 publish/ 拷过去 → 双击 ClassNote.exe
```

也可以直接分发安装程序 `dist/ClassNote-<版本>-setup-x64.exe`（约 275MB，自包含，按当前用户安装、免管理员）。

> 若分发渠道对大文件/多文件不便，可自行压缩为 zip（建议排除 `*.pdb` 以减小体积）；
> 解压后目录结构必须保持完整（`models/`、`assets/`、`LatoFont/` 等不能拍平）。
>
> 体积参考：`publish/` 约 460MB（其中 SenseVoice 模型约 240MB）· 安装程序约 275MB（lzma2 压缩）。

## 3. 安装与首次使用

### 3.1 安装（免安装绿色版）

1. 解压 zip 到任意目录（如 `C:\Program Files\ClassNote\` 或用户目录）。
2. 双击 `ClassNote.exe` 启动。
3. **仅当使用「依赖框架版」发布包时**，目标机需先装 .NET 8 Desktop Runtime：
   - 下载地址：<https://dotnet.microsoft.com/download/dotnet/8.0>（选 **Desktop Runtime 8.0.x**）。
   - 或命令行：`winget install Microsoft.DotNet.DesktopRuntime.8`
   - 判断方法：发布目录里有 `coreclr.dll` + `hostfxr.dll` 即为**自包含**版，**无需**装 .NET
     （`publish/` 与 `dist/ClassNote-<版本>-setup-x64.exe` 都是自包含版）。

### 3.2 首次配置（LLM API Key 与录音）

设置窗口分**两个页签**（v0.5.0）：**「API 配置」** 与 **「录音设置」**；每个页签内容可滚动，窗口空间不足时用鼠标滚轮上下滑动。

**① API 配置页签**

1. **API 基础地址**：默认 `https://api.deepseek.com`（本地 LLM 填其 OpenAI 兼容地址，如 `http://127.0.0.1:11434/v1` 等）。
2. **API Key**：DeepSeek 或任意 OpenAI 兼容平台密钥（仅存本机 `settings.json`，DPAPI 加密）。
3. **模型名称**（**下拉选择**）：地址与 API Key 都填好后，程序会自动拉取该供应商的可用模型列表
   （`GET {地址}/v1/models`）供选择；也可点右上角「刷新模型列表」重新获取，或**直接手输**自定义模型名。
   未联网 / 拉取失败不影响使用：保留原有候选与已保存的模型名，提示行里会说明失败原因。
4. **请求超时（秒）**：默认 1800（30 分钟），范围 60–7200。**本地模型推理较慢时请调大**（如 3600），可减少超时报错。
5. **测试连接**：点击后用当前填写值检测 v1 接口（`GET /v1/models`），正常显示绿色"服务正常"，不可达显示红色原因。

> v0.5.0 起**不再提供**「备用 API Key / 备用 API 基础地址」：一个供应商一套配置。
> 旧 `settings.json` 里残留的这两个键会被自动忽略，不影响升级。

> **长课程会分段生成笔记（v0.6.0）**：素材超过单窗口上限（约 6000 字）时，程序按 400 字重叠
> 切成多段、**逐段调用 LLM 整理、再合并**成一篇笔记，避免旧版本"超出部分直接丢弃"。
> 影响：①一节 90 分钟的课通常约 4–5 段 → **约 5–6 次 API 调用**，耗时与费用按调用次数计
> （每次调用各自受「请求超时」约束，不是总时长）；②笔记页/PDF 会标注"共 N 段整理"；
> ③段内失败会在笔记中标记该段缺失、其余段照常合并，不会整篇失败。

**② 录音设置页签**

6. **声音来源**（默认用于「开始记录」与定时记录，v0.6.0 起固定三种）：
   - **仅麦克风**：默认项，等同旧版本行为（教室现场人声）；
   - **仅系统声音**：录制所选播放设备正在输出的声音（在线课程 / 视频），走 WASAPI 回环采集；
   - **麦克风和系统声音**：两路**分开录成两个文件、分别转写**，笔记里会标明哪些内容来自「现场」（老师讲的）、
     哪些来自「课件」（课件/网课里播的）。适合既要现场人声又要设备声音的课堂；
     **代价是两路各跑一次语音识别，处理时间约为单路的两倍**。
7. **麦克风设备** / **系统声音来源设备**：按所选来源显示对应下拉，留空即系统默认设备。
   - 选 **仅系统声音** 或 **麦克风和系统声音** 时，请选**实际在出声**的那个播放设备（选错会录成静音）；
     两者都会使用这里的播放设备，选「麦克风和系统声音」时麦克风沿用上面的麦克风设备；
   - 指定设备已拔出/改名时会回退系统默认设备，并在录音启动失败信息里说明；
   - 定时记录没有弹窗选择机会，固定使用此处配置的来源与设备。
8. **课堂占用**（v0.7 新增）：录音期间允许借多少 CPU 来**提前**转写。
   - **关闭（全部课后处理）**：行为与 v0.6.0 完全一致——录音期间不跑推理，所有转写留到点「结束录音」之后；
   - **自动（推荐，默认）**：录音期间按 30 秒一块增量转写，**最多只用一半逻辑核**，
     并在检测到**全屏放映 / 视频播放 / 电池供电**时自动降速让路；
   - **极速（课堂期间也全力转写）**：不打占空比的折扣（仍然只占一半逻辑核），
     适合机器核数多、或这节课不放视频的场景。
   - 不论哪一档都**不会**与正在播放的 PPT / 视频抢满机器；详见开发文档 2.6.2。
9. 点「确定」保存。未配置 API Key 时，笔记会以「转写 + OCR 原文」兜底生成（STT/OCR 仍可用）。
   - 主页面右上角的 **LLM 状态胶囊**每 30 秒自动检测一次服务：灰=未配置 Key、绿=服务正常、红=服务不可达；点击胶囊可直接打开设置。

### 3.3 主页面使用（v0.5.0 改版）

主页面为**整宽单栏**布局（旧版的左侧「选择课程」栏已移除），顶部是一排文字按钮：

| 按钮 | 作用 |
|------|------|
| **开始记录** | 打开配置弹窗，在其中确认**课程**（内置 9 门，也可自定义输入）、标题与录音来源 / 设备，然后开始录音 + 自动截屏 |
| **刷新列表** | 重新读取本地记录列表 |
| **定时记录** | 进入「每周课表」页（课表编辑、到点自动录音、开机自启） |
| **设置** | 打开设置窗口（API 配置 / 录音设置两个页签） |

「最近记录」卡片：

- **科目筛选**：左侧「科目」下拉框默认 **全部课程**，列表按**时间从新到旧**排列；选择某个科目即只显示该科目的记录（右侧显示「共 N 条」与「已按科目筛选」）。筛选后无结果时会提示「当前科目下暂无记录，可在上方切换「全部课程」」。
- **单条记录**：**双击**打开笔记；**右键**（或键盘 `Shift+F10`）弹出菜单 → **查看笔记 / 导出 PDF / 删除**。单条「导出 PDF」会另存到所选文件夹（重名自动追加序号），删除会连同录音、截图与笔记一并永久移除。
- **批量操作**：行首勾选框多选，「全选」为三态（全选 / 部分 / 未选）；「批量导出 PDF」与「删除」只作用于**当前筛选出的勾选记录**——被筛选条件排除的记录不会被误删。尚未生成笔记的记录在批量导出时自动跳过，单条导出时会明确提示。
- 每条记录的时间戳含**星期几**（如 `2026-08-30 23:34 周日`）。

### 3.4 数据与文件位置

首次运行后自动创建：

```
%LOCALAPPDATA%/ClassNote/
├── classnote.db          # SQLite 数据库（会话/截图/笔记/课表/转写块）
├── settings.json         # 应用设置（LLM Key、录音来源与设备、课堂占用档位；Key 为 DPAPI 密文）
├── audio/                # 录音 WAV
│   ├── {sessionId}_audio.wav        # 单路来源
│   ├── {sessionId}_mic.wav          # 分轨录音：麦克风那一路
│   └── {sessionId}_system.wav       # 分轨录音：系统声音那一路
├── models/sensevoice/    # 仅在随包模型缺失时才需要外部放置（模型三文件）
└── screenshots/          # 截图 JPEG
    └── {sessionId}/*.jpg
```

> 备份 = 复制整个 `%LOCALAPPDATA%/ClassNote/` 目录。
>
> **v0.7 提示**：`classnote.db` 新增 `transcript_chunks` 表（录音期间按 30 秒一块落库的转写结果）。
> 旧版程序打开新版数据库不受影响（会忽略该表）；新版打开旧库时会自动建表（`CREATE TABLE IF NOT EXISTS`），
> 无需手动迁移。删除某条记录时该表的对应行会一并清理。

## 4. 常见故障排查

| 现象 | 可能原因 | 处理 |
|------|---------|------|
| 启动提示缺 .NET | 目标机未装 Desktop Runtime | 安装 .NET 8 Desktop Runtime 或改用自包含发布包 |
| 「语音识别模型缺失」 | `models/sensevoice/` 未随程序分发 | 确认模型三文件与 exe 同级；或复制到 `%LOCALAPPDATA%/ClassNote/models/sensevoice/` |
| 识别结果为空 / 乱码 | 模型文件损坏 / fbank 参数不符 | 重新拷贝模型文件；开发版检查 `FbankExtractor` 补零与 CMVN |
| 截屏功能无反应 | 系统权限 / 屏幕分辨率过高 | 检查 Windows 截图权限；改低分辨率测试 |
| 笔记生成失败（提示 API 错误） | API Key 无效 / 余额不足 / 网络 | 检查「设置」中的 Key、BaseUrl、模型名；确认可访问 api.deepseek.com |
| 笔记生成慢 / 报"响应超时" | 本地模型推理慢、输入 token 多 | 在「设置」中调大"请求超时（秒）"（如 3600）；查看主页右上角 LLM 状态胶囊确认 v1 接口在线；确认模型已加载完成。**v0.7 起转写已在录音期间完成**，点「结束录音」后通常只剩最后不足 30 秒的音频要补，若仍等待很久请确认「课堂占用」没有被设为「关闭」 |
| 点「结束录音」后很快回到主页，但记录长时间停在「处理中」 | 处理管线异常 | v0.7 起未预期异常会把会话置为 `failed` 并给出原因（不再永久停在 processing）；若为 `failed`，优先看 `models/sensevoice/` 是否齐全与磁盘是否写满 |
| 笔记内容比预期少 / 某一时段缺失 | 课堂期间发生过让路暂停或队列丢帧，那一段音频的块未被即时转写 | 属设计内行为：缺失的块会在课后自动补算，内容不会丢。反复出现可把「课堂占用」调为「极速」，或查看录音页提示里是否显示"已让路" |
| 录音期间机器发烫 / 风扇响，或 PPT 放映出现卡顿 | 课堂占用档位偏高，或外部负载探测未生效 | 「设置 → 录音设置 → 课堂占用」改为「关闭（全部课后处理）」即可完全不在课堂跑推理；正常档位下转写固定只用一半逻辑核，检测到全屏放映 / 视频播放 / 电池供电时会自动降速 |
| 录音页看不到「课堂转写：现场 12:30」这行进度 | 「课堂占用」设为「关闭」，或本次来源无需增量转写 | 属正常：关闭档不跑课堂转写，行为与 v0.6.0 一致 |
| **公式显示成「d / i / j」三行居中大字，或括号消失、变量变斜体** | v0.7 之前版本的 MathJax 分隔符配错（把圆括号/方括号当成了公式分隔符），**渲染侧缺陷** | 升级到修复版即可，**不需要重新生成笔记**——已有笔记会直接正常显示（实测同一份笔记：事故配置 59 个假公式 → 修复后 0 个） |
| **导出的 PDF 里出现 `**` 星号、`$` 美元符或反引号** | v0.7 之前 PDF 导出直接打印 Markdown 原文 | 升级到修复版重新导出即可。注意 PDF 不做数学排版，公式以原文呈现（如 `d_{i,j} = 1 + d[i-1][j-1]`） |
| 笔记里公式没有排成数学样式（仍是普通文字） | 模型没有用 `$...$` 包裹公式 | v0.7 已在提示词里加入"公式用 `$...$` 包裹、只补分隔符不改内容"的要求；若个别笔记仍未包裹，公式仍会以原文正常显示，不影响可读性 |
| 会话时长比实际录音短约 4% | v0.7 之前用 UI 定时器 tick 累加计时，UI 线程忙时 tick 被推迟 | 升级到修复版；修复后用墙钟（`Stopwatch`）计时，与实际音频长度一致 |
| 使用 USB 外接麦克风无法录音 | 所选设备与采集后端不匹配 / 设备被占用 | v0.3.5 起优先走 WASAPI 并按**稳定设备 ID** 选择（不再按名称二次解析）；仍异常时检查 Windows 麦克风隐私设置、确认该 USB 设备未被其他程序独占，或在 Windows 录音设置中将其设为默认设备 |
| OCR 不识别中文 | 系统未装中文 OCR 语言包 | 设置 → 时间和语言 → 语言 → 添加"中文（简体）"语言包 |
| PDF 导出乱码 | 系统无中文字体 | 安装任意中文字体（微软雅黑 / 宋体均可）；程序会自动注册 |
| 录音无声音 | 麦克风未授权 / 默认设备错误 / 采集后端不匹配 | 检查 Windows 麦克风隐私设置（"允许桌面应用访问麦克风"）；「设置 → 录音设置」中选择正确设备；v0.3.5 起 WASAPI 优先 + 稳定设备 ID 选择，如仍无声可尝试在设置窗口重新选择麦克风 |
| 选了「系统声音」但录出来是静音 | 播放设备选错 / 当时确实没有声音在播放 | 确认「设置 → 录音设置」里选的是**实际在出声**的那个播放设备；回环采集只录该设备正在输出的声音，无播放时长为正常静音（可用 `devtools/AudioProbe` 真机校验格式与时长） |
| 混合来源提示"混合录音启动失败" | 其中一路（麦克风或系统声音）打不开 | 报错文本会指明是哪一路；按提示检查对应设备是否被独占/已拔出，或先改用单一路来源确认另一路正常 |
| 系统声音录成静音 | 回环采集的播放设备选错（声音在另一个设备上输出） | 在「设置 → 录音设置」把「系统声音来源设备」改成**实际在出声**的那个（耳机 / 扬声器 / 虚拟声卡要区分清楚）；留空表示跟随系统默认播放设备 |
| 模型名称下拉是空的 | 地址/Key 未填、地址错误、Key 无效，或该地址没有 `/v1/models` | 先点「测试连接」确认接口可达；提示行会给出具体原因（401 = Key 无效，404 = 无该接口）；也可直接在框里手输模型名 |
| 内存占用高 | STT 模型加载 | 属正常现象（峰值约 600MB）；长音频自动分块。**v0.7 起模型全进程只加载一次**（旧版每个录音会话重载一次且跨会话不释放，实测 3 个会话累积到 1.8GB）；**并且闲置 10 分钟后会自动释放、下次用到再加载**（实测：加载后 WS 551MB → 闲置释放后 64MB，重载对用户不可见，因为预热是在开录之后做的）。播放视频被让路 40 分钟这类真实空闲也会触发释放 |

## 5. 升级 / 迁移

- **升级**：停止旧版程序 → 用新版覆盖解压（保留 `%LOCALAPPDATA%/ClassNote/` 数据目录即可，数据库自动兼容）。
- **迁移到新机器**：拷贝数据目录 `%LOCALAPPDATA%/ClassNote/` + 新版程序目录。
- **降级退回旧 STT**：旧版（Whisper）与新版（SenseVoice）数据格式兼容（同一套 sessions/notes 表），仅 STT 引擎不同。
- **v0.6.0 → v0.7 升级**：数据目录无需任何处理。`classnote.db` 会自动补建 `transcript_chunks` 表；
  旧 `settings.json` 缺少 `ClassroomTranscription` 字段时按默认「自动」处理（不写回文件，直到用户点一次「确定」）。
- **v0.7 → v0.6.0 降级**：同样无需处理——旧版会忽略 `transcript_chunks` 表与 `ClassroomTranscription` 字段
  （反序列化时被忽略，不会导致读取失败），只是失去"边录边转写"这一项提速。
- **公式渲染修复是否影响已有笔记**：不影响。修复在**渲染侧**（笔记页的 MathJax 配置与 CSS、PDF 的行内文本处理），
  笔记内容一字未改，因此**历史笔记升级后直接正常显示，无需重新生成**。
  这也意味着：如果某条历史笔记当时是把坏掉的版面照抄下来的（例如 OCR 把下标读成了多行），
  升级后它会以"多行"的原样显示——那属于素材问题，需要重新录制/重新生成才能改善。

## 6. 安全与隐私

- 录音与截图**仅存本机**，不上传任何服务器。
- LLM 调用时，转写文本 + 截图 OCR 文本会发送给你配置的 API 服务商（默认 DeepSeek）。
  如涉及敏感内容，请自行评估或更换本地 LLM 端点。
- API Key 以 **DPAPI 加密**（`dpapi:` 前缀密文，绑定当前 Windows 用户）存储于 `settings.json`；换用户/换机器后需重新配置。请勿将数据目录分享给他人。
- **v0.7 边录边转写不改变任何网络行为**：转写与 OCR 全程本地完成，中间结果（`transcript_chunks`）只写进本机
  `classnote.db`，不新增任何上报。
- **课堂资源让路的探测也只是本机读取**：只读取前台窗口位置、屏幕变化、电源状态与自身进程 CPU 时间，
  用于决定"能不能借 CPU"，不做采集、不外发、不写日志到文件。
- 「结束录音」后立刻回主页**不代表**数据已归档完成：归档与处理在后台继续。此时直接关机会丢失尚未归档的音频，
  建议等主页该条记录显示「已完成」再退出。
