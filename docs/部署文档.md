# ClassNote 单机版 — 部署文档

> 面向部署 / 分发 / 运维人员：从源码构建发布包、分发给最终用户、安装配置与故障排查。
> 适用版本：无服务端单机版（SenseVoice ONNX STT）。

---

## 1. 系统要求（最终用户）

| 项目 | 最低 | 推荐 |
|------|------|------|
| 操作系统 | Windows 10 1809 (x64) | Windows 10 22H2 / Windows 11 x64 |
| 处理器 | x64，4 核 | 8 代 i5 以上 |
| 内存 | 8 GB | 16 GB |
| 磁盘 | 2 GB 可用 | 4 GB（含录音/截图增长） |
| .NET 运行时 | .NET 8 Desktop Runtime（若为自包含发布则免） | — |
| WebView2 Runtime | Windows 10/11 通常已内置；缺失时提示安装 Evergreen 版 | — |
| 麦克风 | 可用录音设备 | 独立麦克风/耳机 |
| 网络 | 仅 LLM 笔记生成需要（DeepSeek API） | 稳定网络 |

> **重要**：STT 模型加载峰值内存约 600MB（240MB 模型 + 推理中间张量），
> 8GB 内存即可顺畅运行；若机器内存较小，长音频可分块推理（代码已按 30s 分块）。

## 2. 发布 / 打包步骤

### 2.1 从源码生成发布包

在 **开发机**（已装 .NET 8 SDK）执行：

```bash
cd ClassNote-Standalone/ClassNote

# 还原依赖（使用项目自带 NuGet.config：nuget.azure.cn 镜像）
dotnet restore

# Release 构建
dotnet build -c Release

# 发布到独立目录（依赖框架版，目标机需装 .NET 8 Desktop Runtime）
# 注意：对 csproj 发布（对 .sln 发布不支持 --output）；--no-restore 用于已还原过的本地发布
dotnet publish ClassNote/ClassNote.csproj -c Release --self-contained false --no-restore -o publish/
```

若想生成**自包含**（目标机无需装 .NET），需先联网还原运行时包：

```bash
dotnet publish ClassNote/ClassNote.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish/
```

> 说明：`ClassNote.csproj` 已将 `models/sensevoice/`（模型三文件）与 `assets/mathjax-tex-svg.js`
> 配置为 `CopyToOutputDirectory=PreserveNewest`，发布时会自动带入。

### 2.2 分发内容检查清单

发布目录 `publish/` 必须包含：

| 文件 / 目录 | 必含 | 说明 |
|------------|------|------|
| `ClassNote.exe` | ✅ | 主程序 |
| `*.dll` | ✅ | 程序集与依赖（NAudio、OnnxRuntime、QuestPDF、SQLite、Markdig、WebView2 等） |
| `runtimes/win-x64/native/onnxruntime.dll` 等 | ✅ | onnxruntime 原生库（按架构） |
| `runtimes/win-x64/native/SQLite.Interop.dll` | ✅ | SQLite 原生库 |
| `runtimes/win-x64/native/WebView2Loader.dll` | ✅ | WebView2 加载器 |
| `models/sensevoice/model_quant.onnx` | ✅ | **SenseVoice 模型（约 240MB），缺失则 STT 不可用** |
| `models/sensevoice/tokens.json` | ✅ | CTC 词表 |
| `models/sensevoice/am.mvn` | ✅ | CMVN 参数 |
| `LatoFont/` | ✅ | QuestPDF 字体（PDF 导出） |

### 2.3 分发方式

发布完成后，**`publish/` 目录即为最终成品**，直接将该目录（含全部文件/子目录）拷贝或通过
U 盘 / 内网 / 网盘分发给目标机即可，**无需压缩打包**：

```bash
# publish/ 目录本身就是可直接运行的分发包
# 目标机：把整个 publish/ 拷过去 → 双击 ClassNote.exe
```

> 若分发渠道对大文件/多文件不便，可自行压缩为 zip（建议排除 `*.pdb` 以减小体积）；
> 解压后目录结构必须保持完整（`models/`、`runtimes/`、`LatoFont/` 等不能拍平）。

## 3. 安装与首次使用

### 3.1 安装（免安装绿色版）

1. 解压 zip 到任意目录（如 `C:\Program Files\ClassNote\` 或用户目录）。
2. 若目标机未装 .NET 8 Desktop Runtime（依赖框架版），先安装：
   - 下载地址：<https://dotnet.microsoft.com/download/dotnet/8.0>（选 **Desktop Runtime 8.0.x**）。
   - 或命令行：`winget install Microsoft.DotNet.DesktopRuntime.8`
3. 双击 `ClassNote.exe` 启动。

### 3.2 首次配置（LLM API Key）

1. 主页面左下角点「设置」。
2. 填写（字段顺序即窗口内顺序；窗口内容可滚动，空间不足时用鼠标滚轮上下滑动）：
   - **API 基础地址**：默认 `https://api.deepseek.com`。
   - **API Key**：DeepSeek 或任意 OpenAI 兼容平台密钥（仅存本机 `settings.json`，DPAPI 加密）。
   - **模型名称**：默认 `deepseek-chat`（可按平台调整）。
   - **备用 API Key / 备用地址**（可选）：主配置失败时自动切换。
3. 点「确定」保存。未配置 Key 时，笔记会以「转写 + OCR 原文」兜底生成（STT/OCR 仍可用）。

### 3.3 数据与文件位置

首次运行后自动创建：

```
%LOCALAPPDATA%/ClassNote/
├── classnote.db          # SQLite 数据库（会话/截图/笔记）
├── settings.json         # LLM 设置（API Key 等）
├── audio/                # 录音 WAV
│   └── {sessionId}_audio.wav
└── screenshots/          # 截图 JPEG
    └── {sessionId}/*.jpg
```

> 备份 = 复制整个 `%LOCALAPPDATA%/ClassNote/` 目录。

## 4. 常见故障排查

| 现象 | 可能原因 | 处理 |
|------|---------|------|
| 启动提示缺 .NET | 目标机未装 Desktop Runtime | 安装 .NET 8 Desktop Runtime 或改用自包含发布包 |
| 「语音识别模型缺失」 | `models/sensevoice/` 未随程序分发 | 确认模型三文件与 exe 同级；或复制到 `%LOCALAPPDATA%/ClassNote/models/sensevoice/` |
| 识别结果为空 / 乱码 | 模型文件损坏 / fbank 参数不符 | 重新拷贝模型文件；开发版检查 `FbankExtractor` 补零与 CMVN |
| 截屏功能无反应 | 系统权限 / 屏幕分辨率过高 | 检查 Windows 截图权限；改低分辨率测试 |
| 笔记生成失败（提示 API 错误） | API Key 无效 / 余额不足 / 网络 | 检查「设置」中的 Key、BaseUrl、模型名；确认可访问 api.deepseek.com |
| OCR 不识别中文 | 系统未装中文 OCR 语言包 | 设置 → 时间和语言 → 语言 → 添加"中文（简体）"语言包 |
| PDF 导出乱码 | 系统无中文字体 | 安装任意中文字体（微软雅黑 / 宋体均可）；程序会自动注册 |
| 录音无声音 | 麦克风未授权 / 默认设备错误 | 检查 Windows 麦克风隐私设置；录音设置中选择正确设备 |
| 内存占用高 | STT 模型加载 | 属正常现象（峰值约 600MB）；长音频自动分块 |

## 5. 升级 / 迁移

- **升级**：停止旧版程序 → 用新版覆盖解压（保留 `%LOCALAPPDATA%/ClassNote/` 数据目录即可，数据库自动兼容）。
- **迁移到新机器**：拷贝数据目录 `%LOCALAPPDATA%/ClassNote/` + 新版程序目录。
- **降级退回旧 STT**：旧版（Whisper）与新版（SenseVoice）数据格式兼容（同一套 sessions/notes 表），仅 STT 引擎不同。

## 6. 安全与隐私

- 录音与截图**仅存本机**，不上传任何服务器。
- LLM 调用时，转写文本 + 截图 OCR 文本会发送给你配置的 API 服务商（默认 DeepSeek）。
  如涉及敏感内容，请自行评估或更换本地 LLM 端点。
- API Key 以 **DPAPI 加密**（`dpapi:` 前缀密文，绑定当前 Windows 用户）存储于 `settings.json`；换用户/换机器后需重新配置。请勿将数据目录分享给他人。
