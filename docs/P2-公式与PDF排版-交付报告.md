## 2. 关键事实与决策

### 2.1 mhchem 已在随包的 MathJax 里（不需要联网下载）

`ClassNote/assets/mathjax-tex-svg.js`（2.1 MB）**本身就包含 mhchem 扩展**——
实测该文件里能搜到 `mhchem` 与 `\ce`。因此只需在配置里声明加载，
不需要引入新依赖、也不需要联网。这条由 `BundledMathJax_ActuallyContainsMhchem` 锁定：
配置声明加载了 mhchem，随包的那份文件就必须真的带这个扩展——否则页面会**静默**少渲染化学式
（配置看起来是对的，效果却没有）。

### 2.2 LaTeX → Unicode：能转的转，转不了的**原样保留**

QuestPDF 排不了 LaTeX。旧行为是脱掉 `$` 后把 LaTeX 原文印出来，
用户看到的是 `\min(f(n-1)+1)` 这种**源码**。现在：

| LaTeX | PDF 里呈现 | 判据 |
|---|---|---|
| `\min` `\le` `\times` `\alpha` `\Omega` `\infty` | min ≤ × α Ω ∞ | 含义无歧义，直接映射 |
| `x^2` `d_{i-1}` `m_1` | x² dᵢ₋₁ m₁ | Unicode 上下标，逐字符全部可映射才转 |
| `d_{i,j}` | `d_{i,j}`（保持原样） | 逗号没有下标映射 → **整体放弃**，绝不产出"半下标" |
| `\frac{a+b}{c+d}` | `a+b/(c+d)` | 复杂分母加括号避免歧义 |
| `\sqrt{b^2-4ac}` | `√(b²-4ac)` | |
| `\weirdcmd{x}` | `\weirdcmd x` | 认不出来就原样保留，**不猜** |

两个踩过的坑（都写进了代码注释与测试）：

1. **命令正则不能吃掉尾随空格**：早期写成 `\\\s*`，于是 `a \times b` 变成 `a ×b`。
   空格在数学式里是有意义的对齐信息。
2. **分组花括号要去掉，但上下标的花括号必须保留**：`d_{i,j}` 的下标因为转不了而整体放弃后，
   花括号是公式语法的一部分；去掉就变成 `d_i,j`，看起来像逗号是正文。

### 2.3 PDF 仍是"逐行近似排版"，这一条如实说明

方案里原本考虑让 PDF 与笔记页**共用一套渲染**（把 Markdown 解析成块结构再喂给 QuestPDF）。
本轮**没有做**，原因是成本与风险：那需要为 QuestPDF 写一个 Markdown 块级渲染器
（标题/段落/列表/嵌套/表格/引用/代码块/公式），量级不小，且没有真实笔记素材可供对拍验收。

因此当前状态是：
- **一致的部分**：行内标记（加粗/代码/链接/公式）由 `MarkdownInlineText` 统一处理，
  公式现在也走同一套 Unicode 转换；
- **仍不一致的部分**：块级结构各写一套——笔记页走完整 Markdig，PDF 走逐行近似。
  差距集中在表格与嵌套列表（本轮已补上"内容不丢"的版本），以及代码块、脚注等低频结构。

这一条列为**已知未完成项**，而不是"已完成"。

## 4.1 素材溯源：把"这份笔记多可信"摆到用户面前

原先素材质量完全不可见：一张 OCR 出了几十处疑点的截图，和一张干净的截图，在成品笔记里长得一样。
现在 `note.Summary` 会带上这样一句：

> （素材：75 张截图、2 路录音，词典 311 条术语，其中 3 张截图的 OCR 有无法确定性修复的疑点（已标注【OCR不清】））

判定口径：某张截图的规范化结果里出现【OCR不清】即计一次（按截图计数，不按行数累加）。
测试覆盖"有疑点 / 无录音 / 空素材"三种形态。
