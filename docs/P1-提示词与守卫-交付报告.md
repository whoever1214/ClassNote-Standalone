## 1. 这一步治的是什么

化学课那份笔记（`化学.pdf`）有三个病，其中两个的根在提示词与去重规则上：

| 病 | 症状 | 根因 |
|---|---|---|
| **重复 25.4%** | 「金属钠着火时，可用泡沫灭火器或干砂灭火」在「核心知识点」和「重点及易错点」各出现一次 | `Deduplicate` 的键含 `kind`，而模型**每段独立分类**，分裂必然发生 |
| **错断言当事实** | 该句是试卷判断题的**选项原句**（化学上也是错的），却被未加限定地写进「核心知识点」 | 提示词要求"删除所有例题与习题"，模型无处安放试卷原题，只好揉进知识点 |
| **OCR 坏字被照抄** | `Na2C03 古亻本` 被端进笔记 | 提示词要求"宁可保留原文，也不要改写"（P0-α 已在数据层治了一半） |

## 3. 关键设计

### 3.1 去重键只留正文

标题是模型自己起的，`kind` 是模型**逐段独立**判断的——两者都不是"这两条是不是同一内容"的可靠信号。
正文归一化后才是内容本身的指纹。合并时的归类取舍：只要任一实例被判为易错点，
保留的那条就按易错点归类（"易错"比"知识点"更具体，反过来会丢一条易错提示）。

实测口径（由 `Deduplicate_CollapsesTheDuplicationThatWasMeasuredInRealNotes` 锁定）：
一份含 5 条、其中 5 条实为 2 条内容的条目列表 → **合并掉 3 条，剩 2 条**。
旧键同样输入下合并 0 条。

### 3.2 证据标签由**后端核对**，模型说了不算

提示词让模型标注 `evidence`，但口头声明不作数：`NoteQualityGuard` 检查每条声称来自「现场」的正文
在转写里有没有佐证，没有就**降级为「课件」**。

判据刻意保守——正文归一化后的**最长公共前缀**要么覆盖整条正文，要么 ≥12 个字符：
- 整条都在转写里 → 有佐证（模型如实复述）；
- 与转写只有短前缀相同 → 无佐证（模型把课件上的原句缝进了正文）；
- 正常同义改写（公共前缀很长）→ **不降级**，否则「现场」标签会彻底失效——模型几乎不会逐字复述口语。

化学事故句的实测：正文「金属钠着火时，可用泡沫灭火器或干砂灭火」与转写「金属钠着火的时候不能用泡沫灭火器」
公共前缀只有 5 个字 → 判定无佐证 → 降级为「课件」。这条由单测锁定。

### 3.3 为什么不让守卫判断"结论在学科上对不对"

那需要学科知识库，靠规则猜只会更糟。守卫管的是**"这条内容的来源说法是否可信"**——
这正是可核对的部分。学科正确性靠另外两条：原题单独成节（用户看得到那是题）、
以及 P0-α 的疑点标注（用户看得到哪里 OCR 不确定）。

**已有断言的改动（如实列出，全部是"锁的措辞已按新口径演化"）**：

| 测试 | 改动原因 |
|---|---|
| `Deduplicate_SameBodyDifferentKind_KeepsBoth` → `..._MergesAndKeepsTheMoreSpecificKind` | 这条锁的旧行为（含 kind 的键）**正是 25.4% 重复的成因**，反过来锁新行为 |
| `NoteSystemPrompt_KeepsOnlyThreeSectionsAndVerbatimRule` 等 3 个 | 从锁"原封不动"这个措辞，改为锁**分级保真的三条口径**（措辞会演化，口径不能分叉） |

其余 500+ 断言一字未改。

## 5. 尚未测量的部分（如实申报）

- **真实重复率**：本轮没有重跑真实课次的 LLM 生成，因此"25.4% → ?"里的**分子尚未实测**。
  已实测的是**机制**：造成那 25.4% 的条目形态（同一正文、不同 kind、不同标题）
  现在会被合并成一条，旧键下合并数为 0。
- **提示词分级的效果**：同样需要真实素材上的模型输出来衡量。分级规则本身的完整性由测试锁定
  （三处提示词都必须带 `分级保真` / `一个字都不许动` / `逐字一致`）。
- **证据标签的实际命中率**：取决于模型是否照 schema 输出 `evidence` 字段。
  字段缺失不会导致失败（有条目级容错测试），但会让守卫无对象可核对。

要补齐这三个数字，需要化学那次的 `classnote.db` + 两路转写 + 原始 OCR。

## 6. 下一步（P2）

1. **统一渲染**：笔记页用完整 Markdig + MathJax，而 PDF 导出是自写的逐行近似排版
   （表格、嵌套列表、公式全部丢失）——两套实现必须合一。
2. **公式渲染**：笔记页给 MathJax 补 `mhchem`（化学式）；PDF 侧先做
   LaTeX→Unicode 保底（`Na_2O_2` → Na₂O₂），彻底解是离线 SVG 嵌入。
3. **PDF 版式与溯源页**：首部信息（课程/时长/素材概览 + OCR 质量摘要）+ 尾部溯源
   （截图数、低置信数、转写来源、分段数、模型与提示词版本）。
4. **黄金样本 + CI 断言**：把化学案例的四件套（原始 OCR、模型原始回复、最终 MD、PDF）入库，
   断言"输出不得含 `亻 冫 钅 闩 巛 刂`，除非同行带疑点标注"。
